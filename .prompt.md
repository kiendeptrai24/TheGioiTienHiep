# Hệ Thống Mining, Coins và PlayFab

## 1. TỔNG QUAN KIẾN TRÚC

### 1.1 Các Thành Phần Chính
- **Game Server (Netcode)**: Chạy logic tính toán Mining, Coins, quản lý trạng thái
- **Game Client (Unity)**: Hiển thị UI, nhận input từ player, đồng bộ dữ liệu
- **PlayFab Backend**: Lưu trữ dữ liệu lâu dài, quản lý profile

### 1.2 Dòng Dữ Liệu Chính
```
Client (MineClickable) 
  → Server RPC 
    → SpiritStoneMine.SetOwner() 
      → Server tính toán Mining 
        → ResourceStorage.PlusCost() (Coins) 
          → Netcode Sync to All Clients
            → SaveLoadPlayfab.SaveGame() 
              → PlayFab API Update Profile
```

## 2. LUỒNG MINING CHI TIẾT

### 2.1 Phase 1: Client Click Mine
**File**: [Assets/_Project/Scripts/Gameplay/WorldClickable/MineClickable.cs](Assets/_Project/Scripts/Gameplay/WorldClickable/MineClickable.cs)

### 2.2 Phase 2: Server Claim Mine
**File**: [Assets/_Project/Scripts/Networking/GamePlay/DigitalResources/SpiritStoneMine.cs](Assets/_Project/Scripts/Networking/GamePlay/DigitalResources/SpiritStoneMine.cs)

Server nhận RPC:
- Lấy SpiritStoneMine component
- Gọi SetOwner(playerId)
- Gán `_owner` (NetworkObject)
- Gán `_ownerStorage` (ResourceStorage)
- Khởi tạo `_lastProduceTime` từ server time

### 2.3 Phase 3: Server Calculates Production
**Framework**: Server-side Update() loop (Server-only)

Mỗi frame:
1. Check if owner exists
2. Tính `(now - _lastProduceTime) >= miningData.miningTime`
3. Nếu đủ time: Gọi Produce()
4. Update mining progress: `miningData.currentMiningProgress += ticks`

**Produce Method**:
```csharp
private void Produce(int times)
{
    miningData.currentAmount += miningData.yieldPerHarvest;
    _ownerStorage.PlusCost((ulong)miningData.yieldPerHarvest);
}
```

### 2.4 Phase 4: Coins Update (Network Sync)
**File**: [Assets/_Project/Scripts/Networking/GamePlay/DigitalResources/ResourceStorage.cs](Assets/_Project/Scripts/Networking/GamePlay/DigitalResources/ResourceStorage.cs)

ResourceStorage maintains:
```csharp
public NetworkVariable<ulong> Coins = new(
    0,
    NetworkVariableReadPermission.Everyone,  // All clients read
    NetworkVariableWritePermission.Server    // Only server write
);
```

- Server gọi `PlusCost(amount)` → `Coins.Value += amount`
- Netcode sinh ra RPC -> all clients
- Clients nhận event `OnCoinsChanged`
- UI update coins display

### 2.5 Phase 5: Stop Mining
**File**: [Assets/_Project/Scripts/Gameplay/BattleScene/MineOptionUI.cs](Assets/_Project/Scripts/Gameplay/BattleScene/MineOptionUI.cs)

```
StopMine() 
→ MineClickable.UnLink()
→ UnlinkServerRpc() [RPC to Server]
→ SpiritStoneMine.UnLink()
  - _owner = null
  - _ownerStorage = null
```

## 9. SECURITY & VALIDATION

### 9.1 Server-Side Checks
- ✅ Chỉ server xử lý mining, tính toán coins
- ✅ Chỉ server write vào NetworkVariable.Coins
- ✅ Client không thể trực tiếp modify coins
- ⚠️ Server RPC có `RpcInvokePermission.Everyone` → validate sender

### 9.2 PlayFab Validation
- Coins được lưu vào PlayFab profile
- Nên thêm server-side validation: max coins cap, negative check

## 10. EXTENSIBILITY POINTS (Mở rộng)

### 10.1 Thêm Custom Rewards
- Chỉnh `ItemResourseData.yieldPerHarvest`
- Thêm logic vào `SpiritStoneMine.Produce()`

### 10.2 Thêm Khác Resource Types
- Thêm vào `enum ResourceType`
- Tạo mới ItemResourceData subclass nếu cần
- Cấu hình trong ItemPreset

### 10.3 Bonuses & Multipliers
- Server calculate: `baseYield * multiplier + bonus`
- Từ player stats, buffs, events
- Update vào `_ownerStorage.PlusCost()`

### 10.4 Resource Expenses
- `_ownerStorage.MinusCost(amount)`
- ShopRequester đã có example
- Validate balance trước: `HasEnough()`

### 10.5 Custom Save Logic
- Implement `ISaveable`, `ISaveLoadRemote`
- Thêm vào saveManagers list
- Override `LoadData()` & `SaveGame()`

## 12. THƯỜNG GẶP ISSUES & SOLUTIONS

| Issue | Nguyên Nhân | Solution |
|-------|-----------|----------|
| Coins không tăng | Server không handle mining | Check IsServer, IsMining owner valid |
| Coins không sync client | NetworkVariable error | Check write permission (Server only) |
| Coins không lưu PlayFab | SaveGame không gọi | ContextMenu save, hoặc trigger save event |
| Coins ít hơn sau load | PlayFab data old | Check save trước load, internet connection |
| Mine bị others claim | Server side không check | Validate owner trước apply rewards |
